# Originality — principles from references, looks of our own

Utpal's goal: videos that are uniquely his. References teach craft; copying their looks makes a clone. Every video tells a different story in a different way, mixing things freshly.

## Their fingerprints (don't copy)

The agency behind the studied references (an editing agency that also sells its project files) repeatedly uses:
- The same ornate gold picture frame (appears in two different reels).
- One accent colour (often yellow) on black-and-white.
- Italic serif captions, word by word.
- Newspapers / front pages as proof.
- A blank cream page for the "breath" beat.
- CTA: an After Effects file icon + a search bar typing the URL.
- B&W for struggle, colour for success.

Keep the **principle** behind each (an accent colour points the eye; proof objects; a breath before the payoff; colour carries the timeline) and choose a **different expression** every time. When a new reference arrives, add its fingerprints here.

## Default good ideas (use often)

- **Our own transition language from tech itself**: a loading bar filling, a notification sliding in, a QR scan revealing the next scene, a screen glitch, a progress spinner, a chat bubble, a cursor drag, a tab switch. Pick the ones that fit the topic.
- **Real data and real UI for accuracy, AI for atmosphere**: charts generated from actual numbers; real screen recordings dropped into designed scenes.
- **Our own easing character**: one house set of curves, used everywhere, so the motion feels like this channel.
- **Number → object metaphors** invented per story.
- **Era mash-ups** when the story spans time.

## Optional identity elements (only when the video calls for it)

These are tools, not defaults. Suggest them when they genuinely serve the story; don't force them into every video.
- **Hinglish as a visual element** — mixing Devanagari and Latin type (e.g. hero word in Hindi).
- **Utpal inside the world** — his footage cut out and composited into scenes (stepping out of a frame, standing in a server room).
- **Indian material culture as surfaces and proof** — cyber-café counters, Doordarshan-era TVs, UPI QR on a chai stall, Indian tech magazines — when the story is set in or about India.

## Fresh-idea prompt (Phase 3)

For each video, propose 2–3 ideas that no reference has done. Ask:
- What object from *this* story could become the motif and the main transition?
- What would this topic's own interface, material or sound look like as a transition?
- Which two eras or worlds could collide in a revealing way?
- What would surprise someone who has watched a hundred of these reels?

Mark which ideas are new and which come from a reference principle, so Utpal can choose consciously.
