# Visual Hook

The first 3 seconds decide the video. This skill turns that into rules, ideas and storyboards. It does **not** own the look (colours, type, brand) - that belongs to `visual-identity` / `visual-edit`. It owns **what happens to the viewer** in frame 1 to ~3s.

## The evidence this skill is built on

A creator posted the same Vox-style explainer twice. **Same audio (byte-identical), same body, same length (58.4s).** Only the first ~4s of visuals differed:

| | Weak (≈30K) | Strong (≈700K) |
|---|---|---|
| Frame 1 | Busy collage on a board: headline, 5 numbered cars, side photos, labels, blueprint | Calm vintage world map, one glowing light, tiny red sailboats |
| Camera | Flat. We look **at** a pinned picture; motion stays inside its frame | Dives **into** the map: top-down → sea level beside the boats. Flat 2D becomes a 3D world |
| Viewer role | Observer outside the frame | Participant inside the world |
| Life | Objects shuffle | Cloud drifts, sun ray sweeps, boats bob - the world breathes |
| Style | Familiar Vox paper-collage | Same familiar Vox paper-collage |

Both were on-topic and both used a familiar style. **The only variable was immersion. Result: ~20x views.**

Owner corrections that are now rules:
- **Text hook works.** Many people scroll muted. A short, static, readable text line on frame 1 is good. The failure is a frame that is *only* reading (many competing text blocks), not text itself.
- **Familiar taste matters.** Use a style the audience already recognises (Vox collage, map animation, etc.). Familiar look + immersive motion > novel look.
- The story/context comes from Utpal; this skill proposes, he corrects.

## The 4-layer hook (all four, every time)

1. **Visual hook - immersion.** Camera moves *into* the scene within the first second. The viewer must cross a boundary: flat→3D, wide→inside, outside the object→inside it, screen→world.
2. **Text hook - static.** One line, ≤ 7 words, high contrast, no animation gimmicks, readable in < 1s. It states the curiosity, not the answer.
3. **Verbal hook - Utpal's Hinglish.** First spoken line lands on the same beat the camera crosses the boundary. Hand wording to `utpal-yt-script-writer`.
4. **Emotion / question.** Before any explanation, the picture alone must make the viewer feel or wonder something (awe, "wait what?", fear of missing out, "that's me").

All four must point at **the same idea**. The hook visual must belong to the story that follows (reuse its objects later in the video - that keeps the promise).

## Immersion toolkit (camera moves that "let viewers in")

- **Dive-in**: top-down map/blueprint → camera tilts and drops to ground level inside it.
- **Push-through**: push into a photo, screen, lens or eye and come out inside that world.
- **Scale-jump**: macro → reveal huge (or huge → macro inside a tiny part).
- **Flat-to-depth**: a 2D cutout/diagram pops into 3D layers as the camera moves.
- **Morph-match**: object A morphs into object B on a matched shape (lens ring → planet ring, coin → wheel).
- **POV**: the camera *is* the subject (the product, the light ray, the user).
- **Living details** on every shot: drifting particles, light sweep, parallax layers, small bobbing. A still world reads as a slide.

Avoid in frame 1: framed pictures-on-a-board, grids of many items, multi-line headlines, logos/intros, the presenter talking before anything visual happens.

## First-frame checklist

- [ ] One clear subject; eye knows where to look in < 0.5s
- [ ] Static text hook present, ≤ 7 words, not competing with other text
- [ ] Camera motion starts on frame 1 (no static hold)
- [ ] Viewer crosses into the world by ~1–1.5s
- [ ] Style is one the audience knows
- [ ] Visual creates a question/emotion without audio
- [ ] Hook objects reappear later in the video
- [ ] Works muted AND with sound

## Workflow

1. **Get the story** from Utpal (or the source reel/topic). Identify the one curiosity the video answers.
2. **Pick the familiar taste** (ask `visual-identity` / `visual-edit` for the project's style; otherwise propose one).
3. **Propose 3 hook options**, each as: Visual move (from toolkit) · Text hook · Verbal hook (Hinglish draft) · Emotion · How it pays off later.
4. **Utpal picks / corrects.** Do not render or generate video until he approves.
5. **Storyboard** the chosen hook: 4–8 frames for 0–3s, each with timecode, frame sketch (simple SVG/ASCII is fine), camera arrow (push/tilt/orbit), morph notes, text placement, and the spoken word on that beat.
6. **Hand off**: wording → `utpal-yt-script-writer`; look/colour/type → `visual-identity`; cuts, transitions, pacing, animation build → `visual-edit` (or a film-style/rendering skill). Pass them the 4-layer hook + checklist so their design keeps the immersion.

## Output format for a hook proposal

```
HOOK OPTION A - "<name>"
Visual (0–3s): <camera move, start frame → end frame>
Text hook (static): "<≤7 words>"
Verbal hook: "<Hinglish line>"
Emotion/question: <what viewer feels>
Familiar taste: <style>
Payoff later: <where these visuals return>
```

## Worked example (topic: "Why are camera lenses so expensive?")

- Visual: start on a static lens on a table, then **push-through** the front glass; inside, the camera flies between floating glass elements catching light like a cathedral, then stops on one tiny element being polished by hand.
- Text hook: "Ye glass ₹2 lakh ka kyun?"
- Verbal: "Is lens ke andar 17 alag glass hain… aur ek bhi galti, poora lens kachra."
- Emotion: awe + "wait, inside a lens looks like that?"
- Payoff: return inside the lens for each reason (elements, coatings, hand-grinding).
